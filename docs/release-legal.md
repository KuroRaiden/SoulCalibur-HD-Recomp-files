## Publishing this source archive

Keep LICENSE, NOTICE.md, preserved third-party license texts and existing attribution notices with the release. Use a neutral repository description such as “Archived independent Soulcalibur HD/ReXGlue research and handwritten integration source; game assets and generated game code are not included.” Use SPDX identifier BSD-3-Clause for the original project material. Do not describe the project as an official port, endorsed SDK release or a fully working game.

The default copyright attribution is a project alias, avoiding publication of a personal name. Change it if a different public attribution is appropriate; it must accurately represent the rights holders. Original source was AI-assisted. The publisher should confirm rights to human-authored contributions and any imported material, and should not claim that a license creates copyright where none exists.

The archive was constructed from selected source/configuration files, not from the private repository or its history. Game dumps, assets, generated PPC sources, IDA databases, proprietary bytecode, builds, SDK copies, saves, caches, dumps and logs are excluded. Do not upload the private workspace wholesale. Factual maps and interface observations are not treated as a blanket authorization to redistribute game expression.

No website, user service, telemetry or account system is distributed, so this source-only release has no accompanying service terms or privacy policy. A future hosted service, executable release or collection of user data would require its own review. A future compiled release also requires an exact dependency/license audit; these source-archive notices are insufficient to clear SDK binaries.

## Limits requiring case-specific judgment

The files here are release paperwork, not legal clearance. Open-source licensing does not determine whether particular reverse engineering, contract terms, access-control circumvention or distribution is permitted. Obtain jurisdiction-specific legal advice if those questions arise. In the United States, 17 USC 1201 contains conditional interoperability provisions, not a universal exception for game recompilation. This release does not claim that any exception applies.
